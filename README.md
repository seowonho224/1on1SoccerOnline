# ⚽ 1on1 Soccer Online 🏆

> **"전 세계 친구들과 즐기는 짜릿한 실시간 1대1 축구 대결!"**

---

## 🎮 게임 소개

**1on1 Soccer Online**은 유니티(Unity) 엔진으로 제작된 실시간 2D 멀티플레이어 축구 게임입니다. 구글 플레이 게임 서비스(GPGS)를 통한 간편한 로그인과 실시간 매치메이킹을 지원합니다.

---

## 🚀 주요 기능

* **👤 GPGS 연동**: 구글 계정으로 간편하게 로그인하고 업적을 관리하세요.
* **⚔️ 1대1 실시간 대전**: 전 세계 플레이어와 실시간으로 실력을 겨룰 수 있습니다.
* **👕 로비 & 라커룸**: 나만의 캐릭터를 꾸미고 경기 준비를 할 수 있습니다.
* **⏱️ 긴장감 넘치는 경기**: 제한 시간 내에 더 많은 골을 넣어 승리를 쟁취하세요!

---

## 🛠️ 기술 스택 (Tech Stack)

* **Engine**: `Unity 6.4`
* **Backend/Network**: `GPGS`, `Photon Fusion` (멀티플레이어 동기화)
* **Language**: `C#`
* **Version Control**: `Git`, `GitHub`
